# PACE Editor Documentation

Welcome to the PACE (Point-and-Click Engine) documentation! PACE is a visual editor for creating simple point-and-click adventure games.

## What is PACE?

PACE is an intuitive tool that allows you to create interactive point-and-click games without programming knowledge. With a visual interface, you can:

- Create multiple scenes with backgrounds and music
- Add interactive elements that players can click
- Design narrative experiences with text and dialogue
- Export your games as standalone HTML files or web-ready packages

### Design Philosophy

PACE is intentionally designed to be **extremely simple with limited functionality**. It's built for a specific use case:

- **Fast creation** of narrative-based experiences with simple interactions
- **Focused scope**: No complex mechanics or systems to slow you down
- **Quick iteration**: Get your story and scenes working without overhead

### Customization for Developers

The real power of PACE comes from its exports. Games are exported as **organized, readable JavaScript, HTML, and CSS** - essentially a clean template for web developers to build upon:

- **Organized structure**: Clean, understandable code that's easy to navigate
- **Modify anything**: Change the textbox CSS, fonts, colors, layout, and behavior
- **Hackable engine**: The game engine is readable and ready to be extended
- **Add features**: Implement custom mechanics, UI elements, or interactions

Think of PACE as giving you an organized foundation. Build your basic game structure in the editor, then leverage web development skills to customize and extend it exactly how you want.

## Features

- **Visual Scene Editor**: Drag-and-drop interface for positioning elements
- **Rich Media Support**: Images, music, and sound effects
- **Text System**: Typewriter effects and interactive dialogue
- **Export Options**: Standalone HTML or optimized website packages
- **Preview Mode**: Test your game instantly without exporting
