# Getting Started

This guide will walk you through creating your first PACE project and understanding the editor interface.

---

## Creating Your First Project

1. Launch PACE Editor
2. Click "New Project" on the dashboard
3. Enter a project name and click "Create"

?> **Tip:** Choose a descriptive name for your project - you can only rename it by renaming its folder in the Projects directory (`%APPDATA%\pace\Projects\` on Windows or `~/.config/pace/Projects/` on Linux).

---

## Understanding the Interface

The PACE Editor consists of three main areas:

| Area             | Location    | Purpose                                                    |
| ---------------- | ----------- | ---------------------------------------------------------- |
| **Tree View**    | Left panel  | Shows your scenes and elements in a hierarchical structure |
| **Scene Canvas** | Center      | Visual preview of your current scene                       |
| **Inspector**    | Right panel | Properties panel for the selected scene or element         |

![Editor Interface](./assets/editor_interface.png 'Editor Interface')

### Tree View (Left Panel)

- Navigate between scenes
- See all elements within each scene
- Expand/collapse scenes to view their contents
- Select scenes and elements for editing

### Scene Canvas (Center)

- Preview how your scene will look in-game
- Drag and drop elements to position them
- Click elements to select them
- Visual WYSIWYG (What You See Is What You Get) editing

### Inspector (Right Panel)

- View and edit properties of the selected scene or element
- Upload images, audio files
- Configure interactions and behaviors
- Set text, music, and navigation options
